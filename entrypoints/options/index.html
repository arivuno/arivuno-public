Before you enable Arivuno

Arivuno starts off and runs only after you enable it.

To hide YouTube Shorts entry points and interrupt Shorts pages, Arivuno will process the following information on youtube.com:

  • the current YouTube URL;
  • destinations of links on YouTube;
  • visible YouTube page structure; and
  • ordinary click or activation events, only to determine whether the activated element is a Shorts link.

This processing happens locally in your browser and is used only for those features. Arivuno does not retain or automatically transmit this YouTube data.

Enabling Arivuno stores one local setting recording that it is enabled and the version of this disclosure. It does not create an activity history.

Choose Enable Arivuno to agree to this processing and turn on the extension.

Open YouTube

Arivuno will run on YouTube tabs opened or reloaded after activation. Reload any YouTube tab that was already open.
